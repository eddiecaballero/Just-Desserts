========

## Description

A small iOS app demonstrating API integration and a well‑structured architecture built with MVVM, service layers, coordinators, dependency injection, and unit tests to ensure maintainability and clarity.

The service and networking layers use traditional completion‑handler patterns. If I were continuing to develop this project, I would refactor these calls to use Swift’s modern async/await concurrency model to simplify control flow and reduce callback nesting.
